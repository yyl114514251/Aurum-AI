# AI 金融工作台 · 辅助决策原型

> 面向中小金融机构的 AI 辅助决策系统原型 —— AI 只做分析、材料生成与风险提示，不输出买卖/授信最终决策。

## 项目结构

```
ai-finance-system/
├── index.html                          # 单文件自包含应用（双击即用）
├── 01-AI金融市场规模与政策调研报告.md    # 市场规模、监管政策、信创适配
├── 02-金融科技竞品与真实案例数据报告.md  # 竞品矩阵、真实财报数据、风险案例
└── README.md                           # 本文件
```

## 快速开始

1. 双击 `index.html` 在浏览器中打开（无需安装、无需构建、无需服务器）
2. 默认进入**演示模式**：所有 AI 功能由内置规则引擎/模板引擎驱动，可完整体验全部模块
3. 如需接入真实大模型：进入「系统设置」→ 填入 API Key 与 Endpoint（OpenAI 兼容格式，支持 DeepSeek / Kimi / 通义 / 文心等），Key 仅存 localStorage，不上传任何服务器

## 功能模块

| 模块 | 核心能力 | 目标角色 |
|------|---------|---------|
| 智能投研 | 财报解析、研报对比、报告初稿、持仓组合诊断、资讯聚合 | 分析师 |
| 信贷尽调 | 企业风险画像、尽调报告初稿、贷后舆情监控 | 风控岗 |
| 财富顾问 | 客户风险测评、理财方案初稿、合规话术助手 | 客户经理 |
| 小微财务 | 流水归类、现金流预测、财务风险体检 | 普惠金融 |
| 合规审计 | 话术/合同智能质检、全链路留痕、法规检索 | 合规岗 |
| 金融知识库 | RAG 检索（引用来源+页码）、文档入库管理 | 全员 |
| 系统设置 | 模型管理、角色权限、数据安全、关于 | 管理员 |

## 合规与安全

- **AI 输出过滤层**：自动拦截荐股、预测涨跌、承诺收益、保本保息、违规信贷意见
- **强制免责声明**：所有 AI 产出标注"仅供参考，不构成投资建议/授信决策依据"
- **全链路留痕**：每次 AI 调用记录输入/输出/时间/操作人至 localStorage
- **幻觉溯源**：知识库回答附来源文档+页码，无来源标注"请人工核实"
- **XSS 防护**：用户输入一律 textContent 渲染，无 eval/Function
- **CSP**：Content-Security-Policy meta 标签限制资源来源
- **数据不出域**：演示模式纯本地运行；LLM 模式仅发送用户主动输入的 prompt

## 部署

- **本地使用**：双击 `index.html`
- **GitHub Pages**：将本文件夹推送到 GitHub 仓库，启用 Pages 即可
- **私有化部署**：放置于任意静态文件服务器（Nginx / Apache），无后端依赖

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（无框架、无构建步骤）
- ECharts 5.5（jsDelivr CDN，加载失败自动降级为 CSS 图表）
- Hash 路由（8 个视图）
- localStorage 持久化（Key、审计日志、用户偏好）
